# FreeDroid

The free, modern, open-source way to mount Android devices on macOS.

Status: **Pre-alpha** — under active development.

## Requirements

- macOS 15.4 Sequoia or newer
- Xcode 16.3 or newer
- An Android device with USB cable

## Build from source

1. `git clone https://github.com/<org>/FreeDroid`
2. `open FreeDroid.xcworkspace`
3. `⌘R`
